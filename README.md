# Occlusion_behavioural

This repository includes all analysis scripts written for our manuscript entitled "Perception of occluded motion depends on post-occlusion motion information" (bioxriv link). To run the analyses as outlined in the paper, download the data from Zenodo (link), create the python environment uploaded here (installation of R needed with Bayes Factor Package https://cran.r-project.org/web/packages/BayesFactor/index.html), and run through steps (a) and (b). The preprocessed eye-tracking is part of the data release on Zenodo, so the preprocessing step (a) can be skipped. Each analysis notebook corresponds to one of the four experiments. Plots as found in the manuscript and the supplemental data are generated within each notebook. 

Authors: Lina Teichmann*, Grace Edwards*, Kyle A. Behel, Chris I. Baker (LT and GE contributed equally to this work)
